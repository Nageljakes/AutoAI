# BBHatfield Call Centre

A comprehensive lead management, pre-qualification and vehicle knowledge base tool designed for call centre agents to guide conversations and manage lead data with save/snapshot/revert capabilities.

## Project Goals

Build an all-in-one platform for agents to:
- Manage and guide leads through the sales pipeline
- Pre-qualify prospects (NCA, deemed expenses, DTI analysis)
- Access vehicle knowledge base for comparisons and product guidance
- Use conversation guides and scripts based on lead stage
- Save snapshots and revert back to previous states
